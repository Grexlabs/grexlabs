# GrexLabs — Free Keyless AI API Platform

> GrexLabs (https://www.grexlabs.in) is a free, keyless, OpenAI-compatible AI API gateway that serves 314+ large language models from 25+ providers through one endpoint — plus a free, unlimited web search API (Bing, DuckDuckGo, Google, Wikipedia) with India-first results. Free `:free` models need NO API key at all: no signup, no credit card, unlimited requests. Every non-free model requires a valid `sk-gl-` API key; with no key or an invalid key only free `:free` models work.

## Endpoints

### 1. OpenAI-compatible chat completions (primary)
- URL: POST https://www.grexlabs.in/api/v1/chat/completions
- Alt alias: POST https://www.grexlabs.in/gen/v1/chat/completions
- Auth: NONE for `:free` models (no key or any key). All other models: valid `sk-gl-` key required — no key / wrong key → 401, use a `:free` model instead.
- Body: `{ "model": "...", "messages": [...], "stream": false, "temperature": 0.7, "max_tokens": 4096, "tools": [...], "tool_choice": "auto" }`
- Response: standard `chat.completion` — `id`, `object`, `created`, `model`, `choices[].message`, `choices[].finish_reason`, `usage.{prompt_tokens,completion_tokens,total_tokens}` (usage is always present; estimated if upstream omits it).
- Streaming: `text/event-stream`, chunks are `chat.completion.chunk`, terminated by `data: [DONE]`.

### 2. Anthropic-compatible messages
- URL: POST https://www.grexlabs.in/api/v1/messages
- Auth: NONE (keyless).
- Body: `{ "model": "...", "system": "...", "messages": [{ "role": "user", "content": [...] }], "max_tokens": 1024, "stream": false, "tools": [...] }`
- Content blocks: `text`, `image` (base64 source), `tool_use`, `tool_result` — all converted to/from OpenAI format.
- Response: `{ "id": "msg_...", "type": "message", "role": "assistant", "content": [{"type":"text","text":"..."}], "stop_reason": "end_turn|length|tool_use", "usage": {"input_tokens":N,"output_tokens":N} }`
- Streaming: Anthropic events — `message_start`, `content_block_start`, `content_block_delta` (text_delta / input_json_delta), `content_block_stop`, `message_delta`, `message_stop`, plus `ping`.

### 3. Google Gemini-compatible generateContent
- URL: POST https://www.grexlabs.in/api/v1/generateContent?model=<id>
- Auth: NONE (keyless).
- Body: `{ "contents": [{"role":"user","parts":[{"text":"..."}]}], "systemInstruction": {"parts":[{"text":"..."}]}, "generationConfig": {"temperature":0.7,"maxOutputTokens":1024}, "tools": [...] }`
- Vision: parts with `inline_data: { mime_type: "image/png", data: "<base64>" }`.
- Response: `{ "candidates": [{"content":{"role":"model","parts":[{"text":"..."}]},"finishReason":"STOP"}], "usageMetadata": {"promptTokenCount":N,"candidatesTokenCount":N,"totalTokenCount":N}, "modelVersion": "<id>" }`
- Streaming: append `?alt=sse` for server-sent events in Gemini chunk shape.

### 4. Models list
- GET https://www.grexlabs.in/api/v1/models → `{ "data": [...314 models...], "total_count": 314 }`
- Each model: `id`, `name`, `context_length`, `architecture.modality` (e.g. `text+image->text` for vision), `pricing.{prompt,completion}` (free models are `"0"`).
- GET https://www.grexlabs.in/gen/models → OpenAI-style `{ "object":"list", "data":[{"id":"...","object":"model",...}] }`

### 5. Free web search API (no key, unlimited)
- GET https://www.grexlabs.in/api/search?q=<query>&n=20&region=IN
- GET https://www.grexlabs.in/api/v1/search?q=<query>&max_results=10&region=IN
- Engine chain (8s budget): Bing RSS → Bing HTML (base64 `ck/a` unwrap) → DuckDuckGo → Google basic HTML → Wikipedia API.
- India-first: `mkt=en-IN`, `cc=IN`, `setlang=en`, `Accept-Language: en-IN,en;q=0.9`.
- Response: `{ "success": true, "query": "...", "engine": "bing-rss", "region": "IN", "total": 10, "count": 10, "items": [{ "rank": 1, "title": "...", "url": "...", "domain": "...", "favicon": "...", "snippet": "..." }], "results": [...same...], "engines": ["bing-rss"], "timestamp": "..." }`

### 6. Image generation (free, no key) — text-to-image + image-to-image
- URL: POST https://www.grexlabs.in/api/v1/images/generations
- List models: GET https://www.grexlabs.in/api/v1/images/generations
- Auth: NONE (keyless, unlimited).
- Body (t2i): `{ "prompt": "...", "n": 1, "size": "1024x1024", "model": "auto|flux|flux-dev|turbo|fast|quality", "response_format": "url|b64_json" }`
- Body (i2i): same + `"image_url": "https://public-source.png"` (AI DRAW) or `"image_b64": "<base64>"` (freeapi Flux Kontext).
- Models: auto (AI DRAW → freeapi → a0 → seinari failover), flux (AI DRAW), flux-dev (freeapi), turbo (a0), fast (seinari), quality (AI DRAW).
- Response: `{ "created": 1712345678, "provider": "ai-draw", "data": [ { "url": "https://gitee-ai.su.bcebos.com/v1/public/temp/....png" } ] }` (or `b64_json` when requested).
- i2i providers: ai-draw-i2i (public URL), freeapi-i2i (base64).

## Reliability guarantees

- No mid-stream cutout: SSE heartbeats (`: ping`) every 15 seconds; 60-second upstream stall watchdog; clean `data: [DONE]` close.
- No premature timeout: per-attempt budget 20s, total router budget 120s, serverless `maxDuration` 300s.
- Big responses: no artificial output truncation — `max_tokens` is honored when provided, otherwise upstream default.
- OpenAI-shaped errors: `{ "error": { "message": "...", "type": "...", "code": "..." } }` style messages with actionable text; 401 only for premium models without any key; 400 for missing `model`/`messages`; 503 with `attempts` array when every provider fails.
